La página web de fotografía es una plataforma digital creada con el objetivo de mostrar y dar visibilidad a trabajos fotográficos de una manera visual, clara y accesible. Su finalidad principal es ofrecer una experiencia agradable al usuario, centrada en la contemplación de las imágenes, permitiendo explorar galerías fotográficas desde cualquier dispositivo y de forma intuitiva.

Para alcanzar estos objetivos, se ha planteado el desarrollo de una web con un diseño limpio y atractivo, donde la fotografía sea el elemento principal. El proyecto se ha diseñado previamente utilizando Figma, lo que ha permitido definir la estructura general de la web, la disposición de las secciones y el estilo visual antes de comenzar con la fase de desarrollo. Este planteamiento previo ha facilitado la organización del trabajo y ha ayudado a mantener una coherencia estética durante todo el proyecto.

La implementación de la plataforma se basa principalmente en tecnologías web básicas, priorizando la sencillez y la facilidad de uso. El desarrollo del frontend se centra en HTML, CSS y JavaScript, apoyándose en frameworks visuales como Bootstrap o Tailwind CSS para mejorar el diseño y la adaptación a distintos dispositivos. El objetivo no es desarrollar una aplicación compleja, sino una web funcional, visualmente cuidada y fácil de mantener.

Durante el desarrollo del proyecto se ha tenido en cuenta la importancia de la usabilidad. Aunque no se han realizado pruebas exhaustivas con usuarios reales, el diseño se ha planteado de forma que cualquier persona pueda navegar por la web sin dificultad, independientemente de su nivel de conocimientos técnicos. La estructura clara, la navegación sencilla y la organización de las galerías buscan facilitar la experiencia del usuario desde el primer momento.

En cuanto al backend y la base de datos, estos aspectos no se encuentran completamente definidos. Debido a la falta de experiencia avanzada en estas tecnologías, el proyecto se plantea principalmente como una web estática, dejando el uso de backend y base de datos limitado a funcionalidades muy básicas, como un formulario de contacto. En este sentido, se han considerado tecnologías como PHP y MySQL, aunque su implementación quedará supeditada a la complejidad final del proyecto y al tiempo disponible.

Los resultados esperados del proyecto se centran en la creación de una página web visualmente atractiva, bien estructurada y funcional, que cumpla con los objetivos iniciales de mostrar contenido fotográfico de forma clara y ordenada. Se espera que el diseño resulte agradable para el usuario y que la navegación sea intuitiva tanto en ordenador como en dispositivos móviles.

De cara al futuro, el proyecto ofrece múltiples posibilidades de mejora. Entre ellas se podrían incluir una gestión dinámica de las galerías, un sistema de administración de contenidos, la integración de una base de datos para organizar las fotografías o la ampliación de las funcionalidades interactivas. No obstante, estas mejoras se plantean como trabajo futuro, manteniendo en esta fase un enfoque sencillo y acorde al nivel del proyecto.

En conclusión, la página web de fotografía se presenta como un proyecto académico adecuado, que combina diseño visual, tecnologías web básicas y una planificación previa mediante Figma. A pesar de las limitaciones técnicas actuales, el proyecto cumple con los objetivos propuestos y sienta una base sólida para futuras ampliaciones y mejoras.

### **1.1 Objetivos**

La página web de fotografía tiene como propósito principal ofrecer una plataforma visual donde se puedan mostrar y organizar trabajos fotográficos de forma clara, atractiva y accesible. Sus objetivos se organizan en funcionales y generales/estéticos.

#### **Objetivos funcionales:**

* **Facilitar la visualización de contenidos fotográficos:** Permitir al usuario explorar galerías de fotografías de manera sencilla, con una organización clara por secciones o categorías.

* **Simplificar la navegación por la web:** Ofrecer una estructura intuitiva que permita al usuario moverse fácilmente entre las distintas páginas sin dificultad.

* **Mejorar la accesibilidad a los contenidos:** Garantizar que las fotografías puedan visualizarse correctamente desde cualquier dispositivo, ya sea ordenador, tablet o móvil.

* **Ofrecer una experiencia cómoda y práctica:** Permitir al usuario acceder a toda la información y a las galerías sin necesidad de registros ni procesos complejos.

* **Mostrar el trabajo fotográfico de forma profesional:** Presentar las imágenes de manera ordenada y cuidada, resaltando su calidad visual.

#### **Objetivos estéticos / generales:**

* **Diseño limpio y centrado en la imagen:** Crear una interfaz sencilla donde la fotografía sea el elemento principal, evitando distracciones innecesarias.

* **Interfaz atractiva y responsive:** Diseñar una web visualmente agradable, adaptable a distintos tamaños de pantalla y fácil de usar para cualquier tipo de usuario.

* **Coherencia visual:** Mantener una estética uniforme en toda la web, definida previamente mediante el diseño realizado en Figma.

### **1.2 Contextualización**

Vivimos en una etapa en la que la digitalización ha cambiado la forma en la que se consume contenido visual, especialmente en ámbitos como la fotografía. Hoy en día, los usuarios acceden constantemente a imágenes a través de plataformas digitales, pero no todas ofrecen una experiencia clara, cuidada y centrada en la calidad visual. En muchos casos, las páginas web de fotografía resultan poco intuitivas, están sobrecargadas de información o no presentan las imágenes de manera adecuada.

Por otro lado, fotógrafos y creadores visuales necesitan espacios donde mostrar su trabajo de forma profesional, ordenada y accesible, sin depender únicamente de redes sociales o plataformas externas que limitan la personalización del contenido. Contar con una web propia permite presentar los trabajos fotográficos de una manera más cuidada y coherente con la identidad del autor.

Ante esta situación, la página web de fotografía surge como una solución pensada para ofrecer una experiencia visual sencilla y agradable, poniendo la imagen en el centro y facilitando la navegación del usuario. El objetivo es que explorar las galerías fotográficas sea un proceso cómodo, claro y atractivo, independientemente del dispositivo utilizado.

#### **Principales retos:**

* **Saturación visual y exceso de información:** Muchas webs y plataformas presentan demasiados elementos en pantalla, lo que distrae al usuario y resta protagonismo a las fotografías.

* **Falta de organización del contenido:** En algunos casos, las imágenes no están bien categorizadas, lo que dificulta encontrar trabajos concretos o seguir una línea visual clara.

* **Necesidad de accesibilidad y diseño responsive:** El usuario actual accede a los contenidos desde distintos dispositivos, por lo que es fundamental que la web se adapte correctamente a móviles, tablets y ordenadores.

La página web de fotografía busca dar respuesta a estas necesidades, ofreciendo un entorno digital sencillo, accesible y centrado en la imagen, que permita mostrar trabajos fotográficos de forma clara y profesional, mejorando tanto la experiencia del usuario como la presentación del contenido visual.

### **1.3 Justificación**

En la actualidad, los usuarios consumen una gran cantidad de contenido visual a través de medios digitales y demandan experiencias cada vez más cuidadas, claras y accesibles. En el ámbito de la fotografía, la forma en la que se presentan las imágenes resulta fundamental, ya que una mala organización, un diseño poco atractivo o una navegación confusa pueden afectar negativamente a la percepción del trabajo fotográfico. Sin embargo, muchas plataformas existentes priorizan la cantidad de contenido o la rapidez de publicación frente a la calidad visual y la experiencia del usuario.

En este contexto, la página web de fotografía nace con un enfoque centrado tanto en el creador del contenido como en el usuario que lo visualiza. El objetivo principal es ofrecer un espacio digital donde las fotografías puedan mostrarse de forma ordenada, estética y profesional, facilitando su visualización y comprensión sin distracciones innecesarias.

Las necesidades detectadas y la forma en la que la web de fotografía pretende darles respuesta son las siguientes:

* **Dificultad para mostrar el trabajo fotográfico de forma profesional:** En muchas plataformas, las imágenes se presentan de manera desordenada o con limitaciones de diseño. La web propuesta ofrece galerías bien estructuradas, donde las fotografías se muestran en alta calidad y con una disposición cuidada.

* **Saturación visual y falta de claridad:** El exceso de elementos gráficos y publicidad en algunas webs distrae al usuario. En este proyecto se prioriza un diseño limpio y minimalista, donde la imagen es el elemento principal.

* **Problemas de navegación y organización:** Encontrar contenido concreto puede resultar complicado si no existe una buena estructura. La web plantea una navegación sencilla, con secciones y categorías claramente definidas.

* **Falta de adaptación a distintos dispositivos:** Dado que gran parte de los usuarios acceden al contenido desde el móvil, la página web se diseña siguiendo principios responsive, garantizando una correcta visualización en cualquier tamaño de pantalla.

* **Necesidad de una experiencia agradable y fluida:** El usuario debe poder recorrer las galerías sin interrupciones ni procesos complejos. Por ello, la web evita registros innecesarios y mantiene una interacción simple y directa.

En resumen, la página web de fotografía se justifica como una solución que pone en valor la imagen y la experiencia del usuario, ofreciendo un entorno digital cuidado y accesible. Este enfoque no solo mejora la forma en la que se presenta el contenido fotográfico, sino que también refuerza la identidad visual del proyecto y contribuye a una percepción más profesional y coherente del trabajo mostrado.

## **2.1 Metodología de trabajo**

El desarrollo del proyecto se ha estructurado en varias fases, siguiendo una metodología sencilla e iterativa, adecuada para un proyecto de desarrollo web de nivel formativo:

### **1\. Análisis inicial y planteamiento de la idea**

En una primera fase se definió el objetivo principal del proyecto: crear una página web de fotografía con un diseño cuidado, minimalista y centrado en la imagen. Se analizaron diferentes referencias de páginas web fotográficas para identificar buenas prácticas en cuanto a diseño, organización de galerías y navegación.

Esta fase permitió establecer qué tipo de contenido se iba a mostrar (galerías fotográficas, sección de presentación y contacto) y qué funcionalidades básicas serían necesarias, evitando complejidades innecesarias.

### **2\. Definición de requisitos**

Una vez definida la idea general, se concretaron los requisitos funcionales y visuales del proyecto. Entre ellos destacan la correcta visualización de las imágenes, una navegación sencilla entre secciones, un diseño responsive y una estructura clara del contenido.

En este punto también se tuvieron en cuenta las limitaciones técnicas del proyecto, asumiendo que el backend y la base de datos no se desarrollarían en profundidad, centrando el trabajo principalmente en el diseño y la parte visual de la web.

### **3\. Diseño centrado en el usuario (UX/UI)**

El diseño de la interfaz se realizó utilizando Figma, herramienta que permitió crear prototipos visuales de las diferentes pantallas de la web. Se trabajó especialmente la disposición de las galerías, el uso del espacio en blanco y la tipografía, con el objetivo de que las fotografías fueran el elemento protagonista.

El diseño se planteó de forma intuitiva, de manera que cualquier usuario pudiera navegar por la web sin necesidad de explicaciones adicionales.

### **4\. Revisión y ajustes**

A medida que se avanzaba en el diseño, se realizaron revisiones continuas para mejorar la coherencia visual y la usabilidad. Estos ajustes permitieron simplificar elementos, mejorar la jerarquía visual y asegurar una experiencia de navegación fluida.

## **2.2 Diseño de interfaz y desarrollo del software**

### **Diseño de interfaz y flujo de pantallas**

La interfaz de la página web de fotografía ha sido diseñada con especial atención a la estética y a la experiencia de usuario. Desde el inicio, el objetivo fue crear un entorno visual limpio y elegante que permitiera disfrutar de las imágenes sin distracciones.

El flujo de pantallas se ha organizado de forma sencilla y lógica. El usuario accede inicialmente a la página principal, donde se muestra una selección destacada de fotografías o una galería principal. Desde ahí, puede navegar hacia diferentes secciones, como galerías temáticas, una página de presentación del autor y una sección de contacto.

Cada galería se ha diseñado para mostrar las imágenes en alta calidad, cuidando la disposición y el espaciado entre ellas. Se ha evitado la sobrecarga de información, priorizando una navegación clara y directa.

### **Desarrollo del software**

El desarrollo del proyecto se plantea principalmente desde un enfoque frontend, utilizando tecnologías web básicas y accesibles. En cuanto al backend y la base de datos, su implementación se considera limitada o incluso prescindible en esta fase, ya que el objetivo principal es la presentación del contenido visual.
